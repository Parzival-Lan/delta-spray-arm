## 2. 坐标系与符号约定（`optimization/` 实际用法）

| 项 | 约定 |
|---|---|
| 原点 | 静平台中心（三个曲柄轴心所在平面，`z = 0`） |
| Z 轴 | **向上为正**（右手系），所以动平台在静平台下方、`pz < 0`；`calculate_workspace.m:108` 的判据就是 `P(3) < 0` |
| X 轴 | 指向 1 号臂径向 |
| 臂方位角 | `alpha = [0, 120, 240]` 度，从 X 轴**逆时针** |
| 曲柄轴心 | `A_i = (R cos alpha_i, R sin alpha_i, 0)` |
| 曲柄柄端 | `B_i = A_i + L·(cos alpha_i·cos theta_i, sin alpha_i·cos theta_i, -sin theta_i)` |
| `theta = 0` | 曲柄**水平向外**（沿该臂径向） |
| `theta` 正方向 | **向下摆**（因 `-sin theta`，θ>0 → B 的 z 为负 → 更低） |
| 单位 | 长度 **mm**，角度 **度**（Python 侧导入时统一转 m / rad） |
| 动平台球铰 | `P_1 = p + (r, 0, 0)`，`P_2 = p + (-r/2, √3r/2, 0)`，`P_3 = p + (-r/2, -√3r/2, 0)` |

与 `optimization_mimo/` 的两处差异（**不要混用**）：mimo 自称「z 向下为正」却仍用「从 X 逆时针」定臂位，
那是**左手系**；对纯位置计算无影响，一旦引入雅可比叉积、角速度、`tau = Jᵀ F` 就会符号出错。
同时 mimo 的约束式写成 `(pz + L1 sin theta)^2`，等价于 `theta_mimo = -theta_opt`。

## 3. 逆运动学（闭式，两支）

姿态恒定（`R = I`）时三臂解耦，每臂一个标量方程。令 `D = R - r`，对第 `j` 臂：

```
proj = px·cos(alpha_j) + py·sin(alpha_j)
A = pz
B = D - proj
C = (l² - D² - L² - (px² + py² + pz²) + 2·D·proj) / (2L)

disc = A² + B² - C²            disc < 0 → 该臂无实数解（不可达）
theta± = atan2(A, B) ± atan2(sqrt(disc), C)
```

`theta±` 就是肘内/肘外两支。可达判据：`exists 支 ∈ [theta_min, theta_max]`。
这段公式在 `optimize_delta_penalty.m:116-139` 与 `run_delta_optimization.m:165-191` 两处重复出现，完全一致。

**Python 侧要补的约定**：MATLAB 判据是「任一支在范围内就算可达」，**没有固定分支**。
这正好是 W1 会踩的「跳臂」坑——规划一条路径时三支可能各自跳到不同支上。
仓库里必须写死单支，并把「分支翻转」本身当成告警事件，而不是静默接受。

两支的数值差异极大（结果参数下实测，单位度）：

| 目标点 (mm) | `theta-` 三支 | `theta+` 三支 |
|---|---|---|
| `(0, 0, -600)` | −202.00, −202.00, −202.00 | **22.96, 22.96, 22.96** |
| `(0, 0, -800)` | −225.45, −225.45, −225.45 | **46.17, 46.17, 46.17** |
| `(300, 300, -800)`（角点） | −268.37, −267.08, −215.19 | **47.88, 72.15, 90.00** |

`theta-` 全部远超 `[-35.55°, 90°]`，所以**物理支是 `theta+`**，仓库写死取 `theta+`。

顺带一个比「蒙特卡洛噪声」更硬的发现：角点那组的第三臂正好是 `90.00°` = `theta_max` 上界。
也就是说 z = −800 那层的限制**不是几何不可达，而是撞在 GA 设计变量的上界上**
（`vub(6) = 90`，而 `run_delta_optimization.m` 的 `vlb/vub` 里 θ_max 最大只能取 90）。
真机电机若允许超过 90°，工作空间还能更大；重跑优化时应把这一上界放宽再看目标框是否更容易满足。

## 4. 正运动学的正确做法

三组球面方程两两相减只得 **2 个独立线性方程**（第 3 个恒线性相关），几何上代表两个平面的交线；
必须再回代一个球面方程 → 关于沿交线的一元二次 → **两个解，即 FK 的两分支**。

`optimization_mimo/fk_delta.m` 直接把 `(1,2)`、`(1,3)`、`(2,3)` 三行拼成 3×3 方阵求解，
该矩阵秩恒为 2，`abs(det(M)) < 1e-10` 必然成立 → 它实际每次都走 `valid=false; P=[0,0,0]` 早退。
**这个文件不要用**，Python 侧 FK 用球-圆交点法或数值迭代（W1 计划里的那条）。

`calculate_workspace.m` 走 `fsolve` + 5 组固定初值，取第一个 `exitflag>0 且 P(3)<0` 的解——
能用，但初值顺序固定意味着不同采样点可能落到不同分支，工作空间点云里会混进另一支的点。

## 5. 优化问题本身

设计变量 `x = [R, r, L, l, theta_min, theta_max]`，边界：

| 变量 | 下界 | 上界 | 结果 | 是否撞界 |
|---|---|---|---|---|
| `R` 静平台半径 | 80 | 150 | 138.12 | 否 |
| `r` 动平台半径 | 20 | 150 | 133.12 | 否 |
| `L` 主动臂 | 100 | 650 | 406.68 | 否 |
| `l` 从动臂 | 250 | 1100 | 582.08 | 否 |
| `theta_min` | −40° | 10° | −35.55° | 否 |
| `theta_max` | 40° | **90°** | **90°** | **是，顶到上界** |

非线性约束 `basic_constraint`：`theta_max - theta_min >= 30`、`l >= 1.15(R - r + L)`、`r < R`、
**`R - r >= 5`**。结果 `R - r = 5.0014 mm` —— **顶在这个约束的边界上**。

目标函数（最小化）：

```
f = 2·L + l + 1e7 · max_violation
```

`max_violation` 是 30 个检查点（8 角点 + 22 个边中点/面心/四等分点）× 3 臂的**最大**违反量，
取「无实数解时的 `sqrt(-disc)/L`」与「有解但超角度范围时的最近角度差(rad)」二者之大；
另有一条反向惩罚：目标框外扩 150 mm 处的 4 个角点若**也可达**，每次 `+0.02`，即反对过度设计。

验证：`2×406.6849938773964 + 582.0832901594389 = 1395.4532779142317`，
而 `delta_result.mat` 里 `fval = 1395.4532779142316` → **罚项精确为 0**，
即 30 个检查点全部可达且无一处超范围，同时框外 150 mm 处不可达（设计刚好够用）。

GA 配置：`ga` 6 变量、种群 150、代数 150、`CrossoverFraction=0.85`、`mutationadaptfeasible`、
不并行、首代用拒绝采样保证可行；第二阶段在粗解附近加扰动（几何 ±8/5/15/25、角度 ±1/3）做局部精搜。

## 6. 设计目标与作业内容的对应

`target`：`Lx = Ly = 600 mm`，`z ∈ [-800, -350] mm`（450 mm 行程）。
**这台臂的结构优化目标就是「在静平台下方 350~800 mm 的深度内包络一个 600×600 的水平作业面」**——
与视场 60×60 cm 的决定同源，不是巧合。验证用的判据是矩形对角线半径
`sqrt(300² + 300²) = 424.3 mm` 在 5 个高度层都要覆盖：

| z (mm) | −800 | −687.5 | −575 | −462.5 | −350 |
|---|---|---|---|---|---|
| 截面半径 (mm) | 428.5 | 509.0 | 548.6 | 572.0 | 574.5 |
| 对 424.3 的裕度 | **+1%** | +20% | +29% | +35% | +35% |

`z_range = [-987, -145]`、`diameter = 1154.9`、`overall_pass = 1`。

用第 3 节的闭式 IK 逐方向二分求解，复算各高度的**角点方向（45°）可用半径**，与 MATLAB 蒙特卡洛记录对比：

| z (mm) | 解析 45° | 解析最小方向 | 解析最大方向(0°, 沿臂) | MC 记录 | MC − 解析 |
|---|---|---|---|---|---|
| −800 | **424.3** | 424.1 | 426.6 | 428.5 | **+4.2** |
| −687.5 | 505.0 | 504.9 | 507.3 | 509.0 | +4.0 |
| −575 | 552.4 | 552.2 | 554.7 | 548.6 | −3.8 |
| −462.5 | 574.6 | 574.4 | 576.9 | 572.0 | −2.6 |
| −350 | 574.5 | 574.3 | 576.8 | 574.5 | 0.0 |

由此得四条结论：

1. **最深那一层是零裕度**。需求 424.26 mm，解析可用半径 424.3 mm——角点恰好压在可达边界上，
   这是 GA 把 `r` 推到极限的自然结果（约束驱动，不是留了余量）。而 MATLAB 记录的 428.5 mm
   是蒙特卡洛**高估**了 4.2 mm，不能当设计余量用。
2. 蒙特卡洛 + `fsolve` 多初值这套评估的边界不确定度约 **±4 mm，且双向都有**（−3.8 ~ +4.2）。
   原因是 FK 用 5 组固定初值取第一个收敛解，点云里混进了另一解支的点（见第 7 节第 5 条）。
   Python 侧改用解析 IK 做水平集，可以给出确定边界——这本身就是 W1 的一个交叉验证成果。
3. 截面**几乎等圆**（各方向只差 0.6%），所以「工作半径」用一个数近似是安全的；
   最大半径在沿臂方向 0°，最小在 45°~60°，而方形作业面的角点正好落在 45°，即最不利方向。
4. **实际作业面建议放在 z ≈ −600 ~ −450 mm**：角点方向仍有 545~575 mm（对 424 需求裕度 28%~36%），
   对真正的格心需求 339.4 mm 裕度 61%~69%。任何结构改动（喷杆加长、相机支架、`r` 因装配缩小）
   都会直接吃掉最浅那几层的余量，必须重跑验证，不能沿用 `overall_pass = 1`。

## 7. 已知缺陷清单与 Python 侧对策

| # | 缺陷 | 对策 |
|---|---|---|
| 1 | `mimo/fk_delta.m` 线性相关 → FK 恒失败 | 不用该文件；Python 用球-圆交点法 |
| 2 | `mimo/` 是左手系且 θ 与 `optimization/` 反号 | 统一采用第 2 节约定；mimo 目录当考古资料 |
| 3 | IK 判据不锁分支 | 仓库写死单支 + 分支翻转告警（W1/W2） |
| 4 | `r`、`theta_max` 都顶在边界/约束极限 | 说明这两个是**约束驱动**而非性能驱动的选择；样机若 `r` 需更小（装喷杆/相机）必须重优化 |
| 5 | 工作空间靠蒙特卡洛 + `fsolve` 多初值 | Python 侧改用解析 IK 做水平集，能给出确定边界而不是采样最大值；两者对拍即 W1 的交叉验证 |
| 6 | `theta_min/max` 是**三个臂共用**的单一区间 | 真机若三个电机限位不同，需要按臂分别给限位并重跑 |
| 7 | `optimize_delta_penalty.m:18` 注释写 `theta_min >= -50deg`，代码是 `-40` | 文档性错误，以代码为准；重跑前顺手改掉 |
| 8 | **目标函数里没有任何传动质量项**（只有 `2L + l` + 可达性罚项 + 紧凑性惩罚） | 见下方专述 |

**第 8 条展开**：GA 只问「够不够得着、连杆够不够短」，从不问「到了那里还能不能好好驱动」。
用 `src/delta/kinematics.py` 复算传动裕度 `min_i |sin μ_i|`（μ = 曲柄与从动臂夹角，0 即死点）：
整个 600×600 作业框在 z ∈ [−800, −350] 各层的最紧值是

| z (mm) | −800 | −650 | −500 | −350 |
|---|---|---|---|---|
| 框内最紧传动裕度 | **0.237** | 0.678 | 0.692 | 0.566 |

也就是说这台臂的传动质量整体不差，但**最深那一层的方形角点正好压在 0.237**，
与「第三臂撞 `theta_max=90°`」是同一个点——可达性、限位、传动质量三件事在那里同时到极限。
重跑优化时应把 `min_i |sin μ_i|` 加进目标（例如 `f = 2L + l + w1·可达违反 + w2·max(0, 0.3 - min s)`），
否则下一次也会优化出同样的"擦边最优"。这条对论文也是一段有用的讨论：
**结构优化必须把传动质量与可达性一起进目标，只优化可达性会系统性擦边。**

## 8. W1 交叉验证基准（从 MATLAB 拿数）

用第 3 节的闭式 IK，取第 5 节的结果参数（换算成 m/rad），下列点应给出确定结果，作为 Python 侧的验收基准：

- 目标框 8 角点：`(±300, ±300, −350)` 与 `(±300, ±300, −800)` mm → 应全部可解且 `theta ∈ [-35.55°, 90°]`。
- 中心低位 `(0, 0, −800)`、中心高位 `(0, 0, −350)`。
- 最底层贴边 `(424.5·cos45°, 424.5·sin45°, −800)` 附近 → 用来检验我们的解析边界是否比蒙特卡洛的 428.5 更宽。
- FK 往返：取 `theta = [-20°, 15°, 45°]` 等随机组，FK→IK 应回到同一支。
