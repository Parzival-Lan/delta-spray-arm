# 00 · 坐标系、单位与作业几何约定

本文件是全仓库的地基。任何一处与代码不一致，W7 的 C++ 逐元素对比就不可能过 1e-9。
改约定必须改代码 + 改本文件，走同一个 commit。

标记含义：`【定】` 已确定不再改；`【待确认】` 需要外部数据才能定，代码里先用占位值并集中定义。

## 1. 帧与原点

- 基座帧 `{B}`：**固定平台（静平台）中心**为原点。【定】
- Z 轴**向下为正**（与重力同向），`g = +9.81`，不在 `g` 前再加负号。【定】
- X 轴指向 1 号驱动臂所在的径向；Y 轴右手系补全。【定】
- 三臂安装方位角 `phi_i = 0, 120, 240` 度（相对 X 轴）。本文件所有工作空间数值只依赖相对角，
  与整体绕 Z 旋转无关。
- 动平台（末端）中心在 `{B}` 下的坐标记为 `p = [x, y, z]`；`z` 即动平台中心相对静平台中心的
  **下移量**，不是离地高度。离地高度 = 静平台离地 `H` − `z` − 喷杆长度。
- 姿态全程恒定，`R = I`（决策三）。本文件所有工作空间与奇异裕度都按**纯平移**计算。

> **术语红线**：仓库内禁止写「上平台 / 下平台」。标准 Delta 电机在顶部静平台，
> 「上平台 = 静平台」；倒置构型相反。一律用 **静平台 / 动平台**（`base` / `platform`）。

## 2. 单位

长度 **m**，角度 **rad**，质量 **kg**，时间 **s**，力矩 **N·m**。
MATLAB / 结构参数若用 mm，导入前除以 1000，且换算只允许发生在数据加载处。

## 3. 结构参数（GA 优化结果，样机）

|---|---|---|

| `r_plat` | 动平台外接圆半径 | 133.1 mm |

## 5. IK 分支

每支链两个解（球-圆交点），全臂固定取同一支，代码里写成常量，**不允许自动切换**。

同一工况点两支解差异极大，例如 `z = 300 mm`、末端横向 `rho = 300 mm`（朝 1 号臂方向）：

| 支 | `q_1, q_2, q_3` (度) |
|---|---|
| 曲柄柄端内摆支 | 134.9, 205.6, 205.6 |
| 曲柄柄端外摆支 | 316.1, 29.0, 29.0 |

选错就是计划里写的「跳臂」。【待确认】MATLAB 用的哪一支、论文里的「肘内」对应哪一支。

注意：**第 7 节的奇异裕度两支数值相同**（两支关于 B–A 连线镜像，传动角不变），
所以安全判据不依赖分支约定。

## 6. 工作空间（纯平移，数值由第 3 节参数算出）

`rho_max` = 该高度下末端能到达的最大水平半径；「朝臂向」取沿某臂径向，「中间向」取两臂角平分线。

| `z` (mm) | 朝臂向 `rho_max` | 中间向 `rho_max` |
|---|---|---|
| 180 | 662.9 | 650.3 |
| 300 | 650.8 | 669.9 |
| 340 | 644.4 | **672.0**（最大） |
| 420 | 626.9 | 668.9 |
| 500 | 602.1 | 655.7 |
| 620 | 547.5 | 614.5 |
| 700 | 496.1 | 560.3 |
| 780 | 427.7 | 469.6 |
| 820 | 384.6 | 414.5 |
| 900 | 268.6 | 271.4 |
| ≥ 990 | 无解 | 无解 |

**作业需求**：25 格最远点是角格 `sqrt(0.30² + 0.30²) = 424.3 mm`。
`z` 在 **180 ~ 800 mm** 区间内均可覆盖，`z ≈ 340 mm` 附近裕度最大（约 58%）。
低 `z` 时水平截面会收缩，但收缩主要发生在 `z > 780 mm`，作业区不受影响。

## 7. 奇异裕度判据与告警阈值

定义：对每支链取 `s_i = |sin∠(E_i − A_i, dE_i/dq_i)|`，三链取最小值。
`A_i` 为动平台球铰中心，`dE_i/dq_i` 为曲柄柄端速度方向。`s → 0` 表示该支链失去驱动末端的
能力（边界奇异）。该量无需完整雅可比，W1 就能实现。

| 工况 | `min s` |
|---|---|
| z=300，格边 300mm | 0.580 |
| z=300，格角 424mm | 0.473 |
| z=450，格角 424mm | 0.635 |
| z=600，格角 424mm | 0.680 |
| z=300，贴边界 650mm | 0.253 |
| z=450，贴边界 650mm | 0.188 |

**【定】告警阈值 `min s < 0.25`。** 它落在作业区（0.47~0.68）与边界（0.19~0.25）之间的空档，
误报与漏报都最少。W2 的「奇异度阈值告警」直接用这个量。

## 8. 相机与作业网格

**构型**：相机与雾化喷头**都装在动平台上**，刚性共动（eye-in-hand），作业采用**两段高度**——
先抬到观测高度 `z_obs` 拍照，再降到喷施高度 `z_spray` 逐格喷。

因此：

- 像素 → 臂坐标的映射里，相机—末端外参是**刚性常量**，一次装配测量得到
  `(dx, dy, dz)` + 绕 Z 安装偏角 `delta`。不需要逐次标定，homography 退化为
  「图像 → 作物冠层平面」的单应 + 这组常量。
- 单应必须用**拍照瞬间的相机离地高度**（对应 `z_obs`），不能拿 `z_spray` 算。混用误差为厘米级，
  与格宽同量级。【定】这条是纪律，不是建议。
- 因为共动，同一帧里第 `(i, j)` 格对应的地面点在臂随后移动时**不漂移**。

### 网格几何

| 项 | 值 |
|---|---|
| 视场边长 `fov_side` | **0.60 m**【待确认】实际由观测高度与镜头视场角反算，见本节末 |
| 网格 `grid_size` | 5【定】 |
| 单格边长 `cell_side` | `0.60 / 5 = 0.120 m` |
| 格心（以视场中心为原点，图像坐标 i 向下、j 向右） | `x_j = (j + 0.5)·cell_side − fov_side/2`，`y_i = (i + 0.5)·cell_side − fov_side/2` |
| 行序映射 | 【待确认】图像第 0 行对应视场的哪一侧。若基座帧 Y 轴与图像下行同向则 `y_i` 直接用；反向则需 `y_i → −y_i` 翻转。**镜像喷施是本项目最典型的翻车方式，W4 第一天必须先验证这一条。** |

`fov_side` 不是自由参数：`fov_side = 2 · h_cam · tan(alpha/2)`，`h_cam` 为相机离地高度，
`alpha` 为镜头（水平）视场角。暂定 0.6 m 需要 `h_cam ≈ 30 ~ 52 cm`（`alpha` 90°~60°）。
相机装在动平台支架上，`h_cam = H − z_obs − 相机在支架上的安装偏移`，故最终视场要等下面三项齐了才算得出。

### 缓冲区换算（重要修正）

`PROTECTION_BUFFER_PX = "auto"` 现在锚定 `15 px @ 3072 px = 1 m 视场`，即隐含 4.9 mm。
视场改 0.6 m 后，同一公式在任何分辨率下都**系统性偏小约 40%**。改为按物理量定义再换算：

```python
buffer_px = max(2, round(PROTECTION_BUFFER_M / fov_side * side))   # PROTECTION_BUFFER_M = 0.005
```

| 输入边长 | 旧 auto 给 | 旧值实际 | 新值（5 mm） |
|---|---|---|---|
| 3072 | 15 px | 2.9 mm | 26 px |
| 1080 | 5 px | 2.8 mm | 9 px |
| 480 | 3 px（被下限夹住） | 3.75 mm | 4 px |

### 分辨率不是瓶颈

推理尺寸 `imgsz = 512`，与输入分辨率无关，有效地面采样距离 `= 0.60 / 512 ≈ 1.17 mm/px`，
比原来 1 m 视场的 1.95 mm/px 还细。1080 或更低分辨率的摄像头够用；`retina_masks` 在 1080 输入下
也不再是关键（它防的是 512→3072 的上采样糊边）。

分级阈值 `determine_dose`（<1% L1 / <10% L2 / <30% L3）与 `protection_threshold = 0.02` 都是占比量，
对分辨率不敏感，**保持不变**。EXG 固定阈值 20 与 HSV 区间同理。只有**绝对像素**的量需要换算。

### 动平台搭载相机的三条连带约束

1. 相机 + 支架质量计入动平台集中负载，即 `m_platform`；这同时是 W3「+30% 负载扰动」的物理来源。
2. 支架会伸入静平台与动平台之间的净空，`z_obs` 越高净空越小，需实测是否与三支连杆干涉。
3. 相机视场上缘可能被连杆遮挡，且喷头/支架会在地面投下阴影；观测位姿需要实测一个不遮挡的方位角。

另：动平台的运动噪声会直接进图像，所以 W6 的抖动注入应当按「加减速时刻的掩膜中心偏移」建模
（与臂运动相关），比高斯白噪声更贴近真实。
