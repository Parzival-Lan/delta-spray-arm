# 00 · 坐标系、单位与姿态约定

本文件是全仓库的地基。任何一处与代码不一致，W7 的 C++ 逐元素对比就不可能过 1e-9。
改约定必须改代码 + 改本文件，走同一个 commit。

## 帧与原点

- 基座帧 `{B}`：**固定平台（静平台）中心**为原点。
- 动平台（末端）中心在 `{B}` 下的坐标记为 `p = [x, y, z]`。
- 本阶段姿态恒为常量，`R = I`；`p` 只描述位置，不含姿态。

> **术语红线**：仓库内禁止写「上平台 / 下平台」。标准 Delta 的电机装在顶部固定平台上，
> 此时「上平台 = 静平台」；倒置构型则相反。一律用 **固定平台 / 动平台**（英文 `base` / `platform`）。

## 轴与角度

| 量 | 约定 |
|---|---|
| Z 轴 | 向下为正（与重力同向），`g = +9.81`，不在 `g` 前再加负号 |
| X 轴 | 指向 1 号驱动臂所在的径向（`theta_1` 的零位方向） |
| Y 轴 | 右手系补全 |
| 关节角 `q_i` | 单位 **弧度**，从各自臂的零位参考起算，正方向为…… |
| 角度符号统一 | 全部逆时针为正（从 1 号臂向 3 号臂看为 `q` 增大方向） |

## 单位

长度 **m**，角度 **rad**，质量 **kg**，时间 **s**，力矩 **N·m**。
MATLAB 里若是 mm，导入前除以 1000，且换算只允许发生在数据加载处，不允许散落。

## 几何参数命名

| 符号 | 含义 |
|---|---|
| `r_base` | 固定平台外接圆半径 |
| `r_platform` | 动平台外接圆半径 |
| `l_1` | 驱动臂（主动）长度 |
| `l_2` | 连杆（从动平行四边形支链）长度 |

## 时间步长

- `sim_dt`：数值积分步长
- `ctrl_dt`：控制周期（W3 起 2ms 或 1ms）

两者必须是不同变量、不同循环，禁止混用。
